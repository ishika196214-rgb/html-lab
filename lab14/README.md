 Lab 14 - CSS Grid Layouts

In this lab we learned grid.

1. grid-first.html - Made 6 boxes with numbers 1 to 6. Used display grid with 3 columns 1fr 1fr 1fr and gap 12px. So 2 rows of 3 boxes.
2. gallery.html - Made Club Photo Gallery with 6 photos Photo 1 to Photo 6. Used repeat(auto-fill, minmax(150px, 1fr)) and gap 10px. So on big screen more boxes fit in one row.
3. dashboard-areas.html - Made layout with header footer sidebar main. Used grid-template-columns 200px 1fr and grid-template-areas. Header and footer across both columns.

Files: grid-first.html, gallery.html, dashboard-areas.html
