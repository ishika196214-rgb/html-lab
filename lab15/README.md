 Lab 15 - Responsive Pages with Media Queries

In this lab we learned media queries and responsive design.

1. mobile-first.html - Made 2 cards in a div class cards. Used viewport meta tag. For phone cards stack vertically. Added media query min-width 600px to show cards side by side with 2 columns.
2. responsive-image.html - Added a heading and an image from images folder. Set max-width 100% and height auto so image shrinks on narrow window.
3. responsive-text.html - Set body font 1rem and h1 1.5rem. Added media query for 600px and up that sets h1 to 2.5rem. So heading becomes larger on big screen.
