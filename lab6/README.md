 Lab 6 - Types of Lists in HTML

This lab demonstrates three types of HTML lists.

1. shopping-list.html
Uses Unordered List `<ul>`.
- Displays shopping items with bullet points.
- Tags used: ul, li

 2. canteen-menu.html
Uses Ordered List `<ol>` and Nested List.
- Displays canteen menu with numbering.
- Sandwich item has a nested list inside it.
- Tags used: ol, li, nested ol
 3. faq.html
Uses Definition List `<dl>`.
- Displays Questions and Answers.
- Tags used: dl (definition list), dt (term), dd (definition)

How to run:
Right click on any .html file > Open with Live Server.
