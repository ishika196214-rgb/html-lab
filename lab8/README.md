This lab demonstrates the use of HTML forms and form controls.

 Files Included

1.  signup.html (Task 1)
    - A basic sign-up form.
    - method="post" and action="thanks.html"used.
    - Contains labelled fields for Full Name, Email, and Password.
    - Labels are linked with inputs using `for` and `id`.
    - Password field uses `type="password"` to hide characters.

2.  choices.html (Task 2)
    - Contains form choices.
    - Gender question using Radio buttons (Female, Male) - only one can be selected.
    - Course selection using a Dropdown / `<select>` with options BCA and B.Tech.

3.  signup-required.html (Task 3)
    - Form with client-side validation.
    - Full Name and Email fields have `required` attribute.
    - Full Name field has a `placeholder="Enter your full name"`.
    - Shows browser's default validation message if submitted empty.

 How to Run
Open any .html file in a browser or use VS Code Live Server to view the forms.
